## 📱 Kaasu — Smart Expense Tracker
An Android expense tracker that installs from Chrome. Type a few words (`chai 20`, `salary 55000`, `gave ravi 2000`), scan bills with the camera, track money given and taken, download reports, and back up to Google Drive. Free to use.

- App folder: [`expense-tracker/`](expense-tracker/)
